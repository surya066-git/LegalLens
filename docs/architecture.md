# LegalLens AI Architecture Notes

This project follows the MVP architecture for a solo developer:

- Next.js + TypeScript frontend
- FastAPI backend
- Page-aware PDF extraction in a later phase
- Clause detection without invented clause numbers in a later phase
- Retrieval-grounded question answering in a later phase
- Citation validation before showing document-specific factual claims in a later phase

The foundation does not include authentication, PostgreSQL, vector search, OCR, or LLM integration yet.
